# 槐木远控 · 开源库（电脑端）

自建远程桌面方案：Windows 作被控端，HarmonyOS 平板作控制端。
串流基于 Sunshine（Moonlight 协议），组网基于 EasyTier，画面只在设备之间直连，不经过任何服务器中转。

> 本仓库由作者私有库导出，外观与官方发行版不同（名称、图标、启动页文案等品牌素材不在开源范围内，详见 [TRADEMARK.md](TRADEMARK.md)）。

## 功能

- 平板远程操作 Windows 桌面，支持触控、键鼠、蓝牙键盘
- 组网自动打通（P2P 直连），会合节点只帮牵线，不转发画面
- 隐私屏（被控端物理屏可熄灭）、虚拟显示器、多屏选择
- 同一账号设备免配对；不同账号可用 6 位控制码临时接入
- 开机即待命：即使没人登录桌面，平板也能连上

## 组成

| 目录 | 作用 |
|---|---|
| `tray2/` | 电脑端托盘程序（WebView2 界面 + 后台逻辑） |
| `streamsvc/` | 串流服务（Windows 服务，托管 Sunshine 与校验口） |
| `tray/` | 两端共用的核心代码（账号、校验口、组网身份） |
| `installer/` | 安装包脚本（Inno Setup） |
| `build/` | 构建与货舱拼装脚本 |
| `payload/` | 第三方二进制货舱（本仓库不含，构建时生成） |

## 快速开始

1. Windows 端：安装发行包，或按 [BUILD.md](BUILD.md) 自行构建
2. 平板端：安装 HAP，与 Windows 在同一局域网或能访问互联网
3. 打开 Windows 端，登录同一账号（或生成 6 位控制码）
4. 平板上点电脑卡片即可连接

> 本仓库里的服务器地址、云环境号都是占位符，**第一次跑之前请先看 [CONFIG.md](CONFIG.md)**，按自己的会合节点填一次（大约 3 处）。
